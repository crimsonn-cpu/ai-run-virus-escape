# AI RUN : 바이러스 탈출 작전
HTML, CSS, JavaScript만 사용한 3레인 러너 게임입니다.  
바이브코딩 실습용으로 Unity 같은 게임 엔진 없이 브라우저에서 바로 플레이할 수 있습니다.
AI 캐릭터 **삐야**와 **오르**가 사이버 세계를 달리며 바이러스를 피하고, 백신을 모아 살아남는 게임입니다.
## 플레이 방법
1. 이 저장소를 클론하거나 ZIP으로 받습니다.
2. `index.html` 파일을 브라우저로 엽니다.
3. 캐릭터를 선택한 뒤 **게임 시작**을 누릅니다.
```bash
git clone https://github.com/crimsonn-cpu/ai-run-virus-escape.git
```
## 조작
| 입력 | 동작 |
| --- | --- |
| ← / 왼쪽 버튼 | 왼쪽 레인으로 이동 |
| → / 오른쪽 버튼 | 오른쪽 레인으로 이동 |
| ↑ / Space / 점프 버튼 | 점프 |
| ↓ | 빠르게 내려오기 |
## 규칙
- 레인은 **왼쪽 / 가운데 / 오른쪽** 3개입니다.
- 시작 목숨은 **5개**입니다.
- 바이러스와 충돌하면 목숨이 1 줄어들고, 잠시 무적 상태가 됩니다.
- 백신을 먹으면 목숨이 1 회복됩니다. 최대 5개까지만 유지됩니다.
- 달리면 점수가 오르고, 바이러스를 피하거나 백신을 먹으면 추가 점수를 얻습니다.
- 시간이 지날수록 속도가 빨라집니다. (EASY → NORMAL → HARD → EXTREME)
- 목숨이 0이 되면 게임 오버입니다. 최고 점수는 브라우저에 저장됩니다.
## 파일 구성
| 파일 | 설명 |
| --- | --- |
| `index.html` | 게임 화면 구조 |
| `style.css` | 사이버 테마 스타일 |
| `game.js` | 이동, 충돌, 점수, 목숨 로직 |
| `piya.png` / `oru.png` | 플레이에 쓰는 캐릭터 스프라이트 |
| `삐야.png` / `오르.png` | 원본 캐릭터 시트 |
| `기획안.md` | 게임 기획안 |
